# Flavour Fusion – AI-Driven Recipe Blogging Platform

## 📌 Project Overview

Flavour Fusion is an AI-driven recipe discovery and blogging platform designed to make cooking, recipe exploration, and meal planning easier and more engaging.

The application provides a centralized platform where users can explore different recipes, search for dishes based on ingredients, cuisine, dietary preferences, and preparation time, and publish their own recipes.

It also includes an ingredient-based recipe generation feature with optional Google Gemini API integration. Users can discover cooking ideas, save their favourite recipes, and organize their daily meal plans through a personalized interface.

## 🎯 Objectives

- Develop an interactive recipe discovery and blogging platform.
- Simplify recipe searching using ingredients and dietary preferences.
- Integrate AI-assisted recipe generation.
- Allow users to publish and share their cooking experiences.
- Provide personalized recipe collections and meal planning.

## ✨ Key Features

- **Recipe Discovery:** Explore a collection of recipes from different cuisines.
- **Smart Recipe Search:** Search recipes using keywords, ingredients, and descriptions.
- **Advanced Filters:** Filter recipes by cuisine, dietary preference, and cooking time.
- **AI Recipe Generation:** Generate recipe ideas using available ingredients with optional Gemini API integration.
- **User Authentication:** Secure registration and login functionality.
- **Recipe Publishing:** Allow registered users to create and publish their own recipes.
- **Favourite Recipes:** Save and manage personally preferred recipes.
- **Meal Planner:** Organize recipes according to dates and meal types.
- **Recipe Details:** View ingredients, preparation instructions, cooking time, and servings.
- **Database Integration:** Store user accounts, recipes, favourites, and meal plans using SQLite.

## ⚙️ Working Methodology

1. **User Registration:** Users create accounts and securely sign in.
2. **Recipe Exploration:** Browse and search available recipes.
3. **Ingredient Selection:** Provide available ingredients for recipe suggestions.
4. **AI-Assisted Generation:** Generate recipe drafts using Gemini integration when configured, with a local fallback otherwise.
5. **Recipe Publishing:** Create and publish recipes with ingredients and preparation instructions.
6. **Recipe Management:** Save favourite recipes and access them later.
7. **Meal Planning:** Organize selected recipes into a personalized meal schedule.

## 🚀 Expected Outcome

Flavour Fusion provides a user-friendly digital cooking platform that combines recipe discovery, community blogging, AI-assisted recipe generation, and meal planning. It demonstrates the practical integration of web development, database management, and generative AI technologies.
